# NGF 8 Week S&C Log

An 8-week, 5-day strength and conditioning training log, built from the original spreadsheet. It installs to a phone's home screen and works offline. Each athlete's log is saved on their own device.

## Use it

Open the GitHub Pages link on your phone, then:

- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** ⋮ menu → Add to Home screen (or Install app)

## Files

- `index.html`, `sw.js`, `manifest.webmanifest`, icons: the live app served by GitHub Pages
- `src/`: the source template, programme data and build script. `src/build_site.py` writes the app files into a `site/` folder next to it; copy them to the repo root to publish a change.
